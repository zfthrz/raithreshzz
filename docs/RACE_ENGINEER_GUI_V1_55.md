# Race Engineer GUI v1.55

GUI v1.55 makes the application-wide keyboard navigation self-documenting.

- `F1` opens a compact, non-modal shortcut reference.
- A visible `Atajos de teclado · F1` action provides the same entry point.
- Repeated `F1` focuses the existing window instead of creating duplicates.
- `Escape` closes the help together with the existing inspector and tooltips.

This is presentation-only. It does not modify telemetry, coaching, History,
calibration, H3 automation, validators or deterministic authority.
